# WanderWish ✈️🌸

WanderWish is a responsive travel wishlist web application built using **HTML, CSS, and JavaScript**. Users can add dream destinations with images, locations, and descriptions dynamically through an interactive form. The project demonstrates DOM manipulation, event handling, and dynamic content creation with a modern pastel-themed UI.

## ✨ Features

* Add vacation destinations dynamically
* Upload destination image URLs
* Store location and description details
* Interactive form handling
* Dynamic DOM manipulation using JavaScript
* Modern pastel-themed responsive UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📸 How It Works

Users can enter destination details through a form, and JavaScript dynamically creates destination cards that appear in the wishlist section without refreshing the page.
